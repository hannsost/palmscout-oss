# Palmscout deployment

These manifests are deployment templates, not an installed or production-certified service.
Use [the root quick start](../README.md#quick-start) for local development and
[configuration](../docs/CONFIGURATION.md) for environment and test setup.

## Build inputs

The hardened API recipe is `deploy/container/backend.Dockerfile`, with context `backend/`.
Provide `PYTHON_IMAGE` as a reviewed Python 3.12 slim image pinned by digest. The frontend
recipe is `frontend/Dockerfile`, with context `frontend/`; `NODE_IMAGE` must be a Node 24
Alpine image pinned by digest. Supply `SOURCE_REVISION` from your release source revision
and `SOURCE_FINGERPRINT` from a reproducible checksum of your release input archive.
No removed internal manifest or local repository history is required by this staging tree.

The frontend build requires explicit HTTPS `NEXT_PUBLIC_API_URL` and `NEXT_PUBLIC_APP_URL`
origins without paths or trailing slashes. They are embedded in browser bundles; changing
runtime environment does not rebuild them. The example.com defaults must be replaced.
Optional public registration/email flags default to false. The build may need network access
for dependencies and fonts. The root Compose file is a legacy local backend setup; its
frontend settings do not satisfy this production build contract.

## Helm templates

`chart/values.yaml` leaves workloads disabled until the operator supplies reviewed image
references and environment. Keep operator-specific values and credentials outside source control.
The empty `webLegal` values are intentional: populate verified operator details per deployment.
Missing fields remain drafts. Secrets are referenced, not generated by the chart.

Use PostgreSQL 16 with pgvector and Redis 7. Configure the matching database user, database,
URLs and independent application keys. Inspect migrations, back up existing data and run
migration jobs before enabling workloads. Review persistent volume permissions, upload storage,
TLS/ingress, CORS, backups/restore and account roles in the target environment.

Validate offline with `helm lint deploy/chart` and `helm template palmscout deploy/chart`
plus an operator-owned values file. These templates do not provision external providers,
DNS, certificates or production credentials. Review optional integrations before enabling them.
